# IP & Subnet Calculator CLI 🌐

Program berbasis terminal (CLI) sederhana yang dibuat menggunakan Python untuk menghitung detail jaringan IPv4 berdasarkan alamat IP dan notasi CIDR. Proyek ini dibuat sebagai latihan pemrograman dan otomatisasi dasar jaringan untuk jurusan Teknik Komputer dan Jaringan (TKJ).

## Fitur
- Menghitung **Network ID** dan **Broadcast Address**
- Menampilkan **Subnet Mask** dan **Wildcard Mask**
- Menentukan **Rentang IP Host Valid** serta jumlah perangkat maksimal
- Mendeteksi jenis alamat IP (**Private** atau **Public**)

## Cara Menjalankan
1. Pastikan Python 3 sudah terinstal di komputer.
2. Clone repositori ini atau unduh file `subnet_calc.py`.
3. Jalankan perintah berikut di terminal:
   ```bash
   python subnet_calc.py
   ```
